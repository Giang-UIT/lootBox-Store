# Sprint retrospective

Date:
13/04/2026

# Sprint execution
This sprint was heavily impacted by the Easter break, which disrupted our pacing. Overall, the sprint did not go as smoothly as Sprint 2, and several tasks were left unfinished and had to be pushed to the backlog for Sprint 4 (specifically, extensive frontend and backend testing). 

# What went well:
- Specific, small tasks like fixing cart images and product page layouts were completed successfully.
- Code review in person continued to be highly effective and helped us understand each other's implementations better.
- Communication remains strong when discussing roadblocks.

# What didn't go well:
- Poor pacing due to the holidays.
- Tasks took much longer than estimated, leaving unfinished work at the end of the sprint.
- We struggled with Git branch naming conventions and committing too many files at once, which caused massive merge conflicts and made the team unsure if we would break the program.

# Adjustments for next sprint:
- Push the comprehensive testing suite (Vitest) to Sprint 4.
- Giang will take over as Scrum Master for Sprint 4.
- Implement stricter rules for branch naming and smaller, more focused commits.
